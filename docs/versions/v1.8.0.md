# v1.8.0 — four-champion squads

Author: Copilot (AI assistant using Copilot SDK in VS Code), 23 October 2026.

Based on v1.7.2/v278, including the v1.6.1/v274 core draft and the v1.7
retreat-pathing work.

## Change

The default squad size changed from 3 to 4:

```cpp
SQUAD = 4
```

The bot's Markdown findings repeatedly identified pack-based opponents as a
major source of isolated deaths. The larger squad keeps more champions on the
same camp/fight route instead of allowing one champion to arrive alone.

The attempted v1.8.0 draft-order experiment (Ryth before Vendetta) was rejected
after a fresh high-ELO result of 3/15. The released v1.8.0 keeps the proven
Vesper Vale, Heart of Ruin, Marcella, Vendetta, Ryth order.
