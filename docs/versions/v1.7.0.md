# v1.7.0 — retreat progress

Author: Copilot (AI assistant using Copilot SDK in VS Code), 23 October 2026.

Based on the v1.6.1 source commit (`12b21df`), submitted as official v274, and
based on the official v1.6.0/v273 release. The v1.7.0 tree therefore includes the v1.6.1 core draft
(`Vesper Vale, Heart of Ruin, Marcella, Vendetta, Ryth`) as well as the v1.6.0
runtime fixes and diagnostics.

## Goal

Improve survival against 1700–1800 ELO teams without discarding the data-backed
draft, ally-vision guards, end-game banking, or diagnostics from v1.6.0.

## Change

### Retreat pathing

`retreat_and_recall()` now scores candidate steps in this order:

1. Preserve the current minimum distance from recently seen threats (allowing a
   one-tile trade when necessary to make progress).
2. Reduce distance to home.
3. Increase separation from threats, up to the existing `RETREAT_SAFE` cap.

Previously, threat distance was the primary score. The v1.6 findings showed
that champions on retreat often gained no home distance and alternated between
approach and back-off when enemies were on more than one side. This change
makes the escape route converge toward spawn while retaining threat avoidance.

## Unchanged proven behaviour

- The v1.6.1 core draft remains Vesper Vale, Heart of Ruin, Marcella, Vendetta,
  and Ryth.
- Enemy sightings are refreshed every turn and ally vision queries remain
  guarded.
- End-game banking still starts when the enemy has submitted 900 gems.
- Death logs and traces remain enabled for ladder diagnosis.

## Validation

The bot built successfully with the repository's cached WASI toolchain and was
submitted as server version **275**. An unranked batch against three opponents
in the requested range completed:

|---|---:|---:|
| cronjohn | 1721 | 3/5 |

| Quantum Tributers | 1708 | 1/5 |
| **Total** | **1708–1766** | **7/15 (46.7%)** |

Across the batch, we submitted 685 gems per game versus 638, collected 1118
versus 821, and killed 8 versus 8. We still averaged 11 deaths and lost 224
carried gems per game. This is a promising farming result but does not yet
demonstrate consistent wins at the target rating.

The initial batch is not a strict paired comparison against v274: the
opponents, maps, and sides were newly sampled. A matched v1.6.1/v274 control
batch is still needed before attributing the improvement to retreat pathing.
