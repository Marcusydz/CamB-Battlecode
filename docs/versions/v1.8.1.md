# v1.8.1 — earlier gem banking

Author: Copilot (AI assistant using Copilot SDK in VS Code), 23 October 2026.

Based on v1.8.0/v280, including the four-champion squad change and the proven
Vesper Vale, Heart of Ruin, Marcella, Vendetta, Ryth core draft.

## Change

The normal gem banking cap was reduced from 60 to 45:

```cpp
GEM_CAP = 45
```

The v1.8.0 near-ELO baseline collected more gems than its opponents but
submitted fewer, while losing 66 carried gems per game. Banking sooner reduces
the amount exposed during the return trip without changing the draft or combat
thresholds.
