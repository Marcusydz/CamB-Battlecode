# v1.2.0

Based on v1.1.0 (official v267). Submitted as official v268.

## Changes

| Change | What it does |
|---|---|
| `MAP_FIELDS` (new, on) | Each champion computes a distance map to every camp group once per match, from fuel left over at the end of its first turns. After that, choosing a camp is a lookup, not a new path search every 3 rounds. Ready by round 4 on most maps, round 16 on 100×100 ambush. Checked against the old search: 0 mismatches in about 1,300 comparisons on 4 maps. Far walks also follow these maps. |
| Crash fix | Ordering target camps (and enemies in range) by danger and health could crash the bot with a wasm `unreachable` trap. `stable_sort` called the camps' virtual `health()` on objects in its move buffer. A crash restarts the bot and it loses everything it knows. Now each key is read once and the indices are sorted (`sorted_by` in `core/util.h`); the resulting order is identical. Found on elk_arena; this code has been there since v1.0.0. |

## Result

Local test against v1.1.0: 700 seeded games (35 maps, both sides, 10 seeds).

| Bot | Wins | Mean gem margin |
|---|---|---|
| v1.1.0 + crash fix (baseline) | 351 / 700 (50.1%) | −11 |
| **v1.2.0** (+ `MAP_FIELDS`) | **370 / 700 (52.9%)** | **+13** |

An earlier 280-game round gave the same direction (146/280, +10, against a baseline of 137/280, −16).
The gain is modest but showed up in both rounds.

## Ladder findings (not in this version)

From 260 ranked games on 21 October (several versions, so treat as hints):

- **Prism first loses:** 8–29 (22%), against 52–28 for Vesper Vale first and 58–64 for Heart of Ruin first.
  Prism goes first only on elk_arena, packs/gold_rush, shortcut and collision, which are among our worst
  maps (elk_arena 0–9, packs 0–4, gold_rush 1–9, collision 2–5). `PRISM_MAPS_LIST` in
  `draft/draft.cpp` (20 = v1.2.0) can switch them to list 17 (Vesper Vale first) or 16 (Heart of Ruin
  first). The local test was stopped before it produced results, so v1.2.0 keeps Prism first.
- **Enemy Vesper Vale:** we win 34% (44 games) when the enemy drafts it.
