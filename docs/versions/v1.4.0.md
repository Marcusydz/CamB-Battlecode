# v1.4.0

Based on v1.3.0. Reworks champion selection so it considers the roster being built and the opponent's revealed picks, while retaining the map preference lists as a stable prior.

## Changes

| Change | What it does |
|---|---|
| Map fit | Builds an automatic profile from contested gem share, wall density, map aspect ratio, and concentration of camp rewards. Candidate champions receive a score for fitting the map's farming and fighting conditions. |
| Team composition | Scores each legal pick for filling missing roles such as frontline, ranged damage, area damage, control, and sustain. Adds small bonuses for useful pairings and penalties for over-stacking roles. Champion traits are based on their documented kits. |
| Matchup | Evaluates the candidate against each revealed enemy pick. Examples include area/burst damage against the linked Cassi & Issac pair and lower control value against stun-immune Marcella. The matchup component is bounded so repeated enemy picks do not grow without limit. |
| Enemy-synergy disruption | Adds value for picks that pressure a revealed ranged-heavy or sustain-heavy opponent composition. The game permits both teams to pick the same champion, so exact champion denial is not possible. |
| Pick diagnostics | Emits a compact line for each selection with the chosen champion and map, team, matchup, and disruption score components. |

The previous map rankings remain a weighted prior so picks stay stable when geometry or matchup evidence is weak.

## Results

Compared with the v1.3.0 source on all 35 maps, both sides, and three seeded variants (210 seeded games), v1.4.0 won **125/210** with a mean gem margin of **+86**. The previous draft scoring won **113/210** with a **+34** mean margin on the same seeds. Across the full run including the unseeded set, v1.4.0 won **153/280**, with a **+47** mean margin. There were **0 bot faults**.

Results vary by map. `01elk-arena` (1/6 seeded games, −504 mean margin) and `00ambush` (0/6, −252) remain weak and need targeted review. `00interlock`, `00pilgrimage`, `00rushbait-v2`, and `01starfish` improved substantially in this comparison. These are local head-to-head results against the previous bot, not ladder results.
