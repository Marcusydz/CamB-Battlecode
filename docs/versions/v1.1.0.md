# v1.1.0

Based on v1.0.0 (official v266). Uses four game rules v1.0.0 ignored (see `docs/UnusedRules.md`),
and splits the bot's code into folders.

## Result

Local test against v1.0.0: 280 seeded games (35 maps, both sides, 4 seeds).

| Bot | Wins | Mean gem margin |
|---|---|---|
| **v1.1.0** | **163 / 280 (58%)** | **+81** |
| v1.0.0 copy (noise baseline, same seeds) | 135 / 280 (48%) | −39 |

All games were against our own v1.0.0, so the ladder is the real test.

## Behaviour changes

Each change has a switch in `bots/main/src/core/config.h`. Setting it to 0 restores v1.0.0's behaviour.

| Switch | Change |
|---|---|
| `HOR_DASH` | Heart of Ruin uses its dash as an attack. It lands where it hits the most enemies or camps (1.5x focus damage and a 1-turn stun around the landing tile), favouring the kill target in fights. Before, the dash was only used for walking. |
| `RANGED_RESET` | A ranged champion that walked this turn casts its attack reset, then attacks (Vesper Vale, Tavi, Willow). Before, walking used up the attack. Checked in the engine: 30 successful reset-and-attacks in one game on rows. |
| `MOVE_RETRY` | A step blocked by an unseen unit (for example in a bush) tries the next two best tiles. The failed step costs nothing. This applies to walking and to retreating. |
| `HOR_SLOT_FIX` | Bug fix: Heart of Ruin now gets its shared-memory slot and team size from the draft. Before, it fell through to a fallback slot (handle mod 8), which could collide with an ally's camp claim. |

Tests that built up to this set (each against v1.0.0):

| Switches on | Wins / 280 | Margin |
|---|---|---|
| `HOR_DASH` | 142 | +2 |
| + `RANGED_RESET` | 148 | +25 |
| + `MOVE_RETRY` | 155 | +60 |
| + `HOR_SLOT_FIX` (v1.1.0) | 163 | +81 |

## Code layout

`bot.cpp` (2,200 lines) is now split by job:

```
src/
  main.cpp
  core/      bot.h, config.h (all switches), util.h, setup.cpp, memory.cpp
  actions/   movement.cpp, combat.cpp, pvp.cpp, economy.cpp
  strategy/  planning.cpp, map_settings.cpp, turn.cpp
  draft/     draft.h, draft.cpp
```

The split itself changes no logic. With unlimited fuel, games against v1.0.0 are identical event for
event. At normal fuel, 5 of 70 games differ, because a few decisions depend on how much fuel is
left and the split moves fuel use by about 0.6%.

`scripts/arena.py` and `scripts/cvariant.sh` now find C++ bots and switches in any source file.
